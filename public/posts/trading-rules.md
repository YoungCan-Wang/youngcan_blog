# 交易复盘：我的趋势交易规则与仓位管理系统

交易是一场反人性的游戏。在这个充满随机性的市场里，任何主观臆测和情绪化操作都将付出惨痛的代币代价。经过多轮牛熊的洗礼，我为自己立下了这套严格执行的“趋势交易与仓位管理规则”。

---

## 1. 趋势确认：只做顺势

我拒绝抄底，也拒绝摸顶。我的系统只操作“已经形成趋势”的行情。

*   **多头市场**：价格站稳在日线 EMA20 和 EMA50 均线之上，且均线呈多头排列。
*   **空头市场**：价格运行在均线之下。若无重大阻力回踩确认，绝不轻易做多。

> [!WARNING]
> **切记**：均线是方向指针，而不是入场依据。不能仅仅因为价格在均线之上就无脑做多，必须等待结构性的突破或回踩。

---

## 2. 突破入场与止损设定

入场的核心逻辑是**支撑阻力位的转换 (S/R Flip)**：

```
     阻力位突破 (Resistance Breakout)
       ▲
      / 
----/-------- 阻力变支撑 (S/R Flip)
  / ＼      /
/     ＼  /  ◄--- 最佳入场点 (Limit Order Buy)
        ▼
```

### 止损的铁律：
- 止损必须在**入场前**确定，并直接在系统下单。
- 止损点位通常设在突破结构前低（多头）或前高（空头）的下方，且单笔交易的最大亏损额不能超过账户总资金的 **1.5%**。

---

## 3. 仓位管理：凯利公式的约束

我通过**凯利公式**的变体来指导单笔仓位：

$$f^* = \frac{p \cdot R - q}{R}$$

其中：
- $f^*$ 为投入资金占总额的比例；
- $p$ 为赢钱概率（历史胜率）；
- $q$ 为输钱概率 ($1 - p$)；
- $R$ 为盈亏比（平均盈利 / 平均亏损）。

为了应对市场非系统性风险，我通常采用**减半凯利公式 (Fractional Kelly)**，即计算出 $f^*$ 后再除以 2 或 3，以获得更平滑的资金净值曲线。

## 4. 经典复盘：近期 BTC 交易解析

在 2026 年 5 月底的一笔 BTC 多单中，系统给出了完美的突破买入信号：

```json
{
  "symbol": "BTCUSDT",
  "entry": 64200,
  "stopLoss": 62000,
  "takeProfit": 67800,
  "reason": "日线双底颈线放量突破"
}
```

*   **执行**：价格放量突破 64,000 美元颈线，回踩 64,200 入场。止损设于双底右侧前低 62,000（相当于亏损 3.4%）。
*   **资金控制**：账户总额 $10,000，限制单笔亏损 $150（1.5%）。计算出合理买入仓位为 $150 / 0.034 = $4,411（杠杆 1 倍左右）。
*   **结局**：价格顺利反弹至日线前高 67,800，触发止盈，斩获 5.61% 的空间，带来 $247 利润。盈亏比接近 1.6 倍。

交易是不确定性的科学。严格执行规则，保护好本金，让概率和时间为你工作，这就是交易唯一的圣杯。
